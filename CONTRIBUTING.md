# Contributing

Thanks for helping make Orbit Lumi more useful.

For a bug, include your browser, device, viewport size, theme, reproduction steps and expected behavior. Never include real passwords or personal data.

For a small fix, fork the repository, create a focused branch and open a pull request explaining your change and checks. Open an issue first for larger changes.

Keep the page usable without a build step. Preserve keyboard navigation, visible focus, reduced-motion behavior and all six themes. Do not add analytics or credential storage.

Run `node tests/smoke.cjs` after interaction changes. Check mobile and desktop layouts, empty-form feedback, password visibility, the lamp, themes and sign-in animation. Code contributions use the MIT license.
